# PowerLab Simulator

Интерактивная модель резервного электропитания дома.

## Стек

React 19, TypeScript, Vite, Vitest. Визуальная схема пока использует совместимый DOM-движок `src/simulator.js`, который подключается после монтирования React. Долгосрочная цель — перенос всех элементов на декларативные React-компоненты.

## Команды

```bash
npm ci
npm run dev
npm run check
npm test
npm run build
```

## Структура

- `src/main.tsx` — React root
- `src/legacy-template.html` — разметка схемы, подключаемая React
- `src/engine/canvas.ts` — типизированная геометрия карты
- `src/engine/canvas.test.ts` — тесты перемещения и размеров карты
- `src/simulator.js` — существующий симуляционный движок
- `src/theme.js` — переключение темы
- `src/styles.css` — оформление

**Важно:** это функциональная симуляция, а не электромонтажная документация. Реальное подключение сети, генератора, инвертора и нейтрали требует проверки квалифицированным электриком.
