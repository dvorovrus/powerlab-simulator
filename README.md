# PowerLab Simulator

Интерактивный симулятор электроснабжения дома.

## Разработка

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm run check
npm run build
npm run preview
```

## Структура

- `index.html` — разметка интерфейса и электрической схемы
- `src/styles.css` — стили
- `src/simulator.js` — логика схемы и симуляции
- `src/theme.js` — переключение темы
- `vite.config.js` — конфигурация сборки

Это первый этап рефакторинга: исходная логика сохранена, но код ещё требует декомпозиции на независимые модули, автоматизированных функциональных тестов и проверки электрической модели. Не используйте симуляцию как инструкцию по реальному электромонтажу.
