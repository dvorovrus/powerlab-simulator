# PowerLab Simulator

Интерактивная модель электропитания дома с резервом от аккумулятора и генератора.

## Возможности

- Городская сеть → стабилизатор 90–310 В, резервный инвертор, АКБ, генератор и каскад АВР.
- Управление входами, автоматами Eaton, селектором зарядки IEK 1-0-2, нагрузкой, SOC и скоростью симуляции.
- Расчёт приоритетов источников, ограничения по мощности, заряд/разряд, сценарии и журнал событий.
- Перетаскивание блоков SVG-схемы, автоматическая маршрутизация линий, увеличение и расширение карты, полноэкранный режим.
- Адаптивная светлая/тёмная темы, моноширинная типографика, иконки Lucide.

## Технологии

**React 19 + TypeScript + Vite 8**. Интерфейс разбит на типизированные React-компоненты, включая shadcn-подобные примитивы `Button` (Radix Slot + CVA) и `Card`. Схема и анимации SVG обновляются через специализированный TypeScript DOM-адаптер, поскольку это высокочастотная визуализация; детерминированный расчёт электроэнергии отделён от DOM и покрыт тестами.

- `src/components/` — Header, Kpis, ControlPanel, ScenarioDock, DiagramPanel, StatusPanels, DetailsPanel, Footer.
- `src/components/ui/` — переиспользуемые shadcn-style компоненты.
- `src/engine/electrical.ts` — строготипизированные электрическая модель и сценарии.
- `src/engine/canvas.ts` — геометрия и расширяемое полотно.
- `src/simulator.ts` — SVG, маршрутизация, перетаскивание, управление и анимации.
- `scripts/smoke.mjs` — end-to-end тест реального браузера Chrome/Chromium.


```bash
npm run check
npm test
npm run build
npx playwright install chromium # на Linux/CI для браузерного теста
npm run test:browser
# или всё подряд:
npm run verify
```

## Публикация

Результат Vite — `dist/`. Пример деплоя: `npx wrangler pages deploy dist --project-name powerlab-simulator --branch main`.

**Безопасность:** симулятор — учебная функциональная модель, **не монтажная схема**. Номиналы защит, соединения L/N/PE, режим коммутации нейтрали, RCD/RCBO и конструкция АВР должны проверяться по паспортам конкретного оборудования и квалифицированным электриком. Не объединяйте нейтрали разных источников без согласованной схемы коммутации.
